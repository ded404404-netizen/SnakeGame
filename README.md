# SnakeGame

A modern web-based Snake game with multi-language support and responsive design.

## Features

- 🎮 Classic Snake gameplay
- 🌍 Multi-language support (Spanish, English, Russian, Chinese, French, German, Japanese, Portuguese)
- 📱 Fully responsive design (portrait, landscape, desktop)
- ⌨️ Keyboard controls (Arrow keys / WASD)
- 👆 Touch controls (swipe + D-pad)
- ⏸️ Pause and restart functionality
- 🏆 Score tracking with high score persistence
- 🎯 Three difficulty levels (Easy, Normal, Hard)
- 📳 Haptic feedback on mobile devices
- ♿ Accessibility features (reduced motion, focus indicators)

## Controls

### Desktop
- **Arrow keys** or **WASD**: Move the snake
- **Space**: Pause/Resume
- **Enter**: Start game

### Mobile
- **Swipe** on the game board to change direction
- **D-pad buttons** below the game board
- **Pause/Restart** buttons available during gameplay

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Language Support

The game automatically detects the browser language and supports:
- 🇪🇸 Spanish (Español)
- 🇬🇧 English
- 🇷🇺 Russian (Русский)
- 🇨🇳 Chinese (中文)
- 🇫🇷 French (Français)
- 🇩🇪 German (Deutsch)
- 🇯🇵 Japanese (日本語)
- 🇧🇷 Portuguese (Português)

Users can switch languages at any time using the language selector in the header.
